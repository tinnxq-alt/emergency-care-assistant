# 急救诊疗助手 v0.9（可编辑临床扩展预览）

这是一个独立的基层急诊、抢救与值班工作台项目，与“基层用药助手”分开维护、分开部署、分开回退。

## 开发预览网址

https://raw.githack.com/tinnxq-alt/emergency-care-assistant/preview/index.html

> `preview` 是公开开发预览指针，不代表正式临床发布；`main` 继续保持稳定基线，当前 Draft PR 暂不合并。

## v0.9：全站临床内容可编辑

所有结构化急症卡、抢救药物卡和临床流程卡均支持本机编辑：

- 编辑显示标题、摘要、红旗征象、首要处置步骤、剂量/参数、液体复苏、复评目标和安全提醒。
- 列表字段按行编辑，可直接新增、删除或调整顺序。
- 支持个人备注。
- 个人编辑保存在浏览器 LocalStorage，不上传患者数据，也不会修改 GitHub 中的指南默认数据。
- 一旦修改，卡片自动显示“本机已编辑 · 需复核”，不再冒充原指南核验内容。
- 原始指南来源、指南年份和默认内容保持独立，可一键恢复。
- 支持导出/导入个人编辑 JSON，以及集中管理和全部恢复默认。

## 产品安全原则

- 泛主诉不自动锚定单一疾病；只有明确诊断或高度特异红旗入口进入疾病指南卡。
- 每条默认临床内容显示核验状态、指南名称、版本和核验日期。
- 用户本机修改与指南默认内容分层显示；个人修改必须重新临床复核。
- 卒中溶栓、主动脉综合征、抗凝逆转、动脉瘤封闭、TIPS/BRTO、危重中毒等复杂高风险治疗不压缩成单一按钮。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定。
- 儿童、孕产妇、特殊人群、药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。

## 技术功能

- 响应式首页与移动端底部导航
- 主诉 / 明确诊断双入口
- 红旗入口与全局搜索
- 抢救用药、急救流程、计算工具、急诊病历、待办
- 收藏与最近使用（LocalStorage）
- 交班快速清单
- PWA manifest、应用图标、基础离线缓存
- 指南来源库和临床核验状态
- 临床内容按 batch 拆分，可独立审查与回退
- 全站结构化临床卡本机编辑、导入/导出、恢复默认
