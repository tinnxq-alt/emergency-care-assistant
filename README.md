# 急救诊疗助手 v0.10（全项可编辑临床预览）

这是一个独立的基层急诊、抢救与值班工作台项目，与“基层用药助手”分开维护、分开部署、分开回退。

## 开发预览网址

https://raw.githack.com/tinnxq-alt/emergency-care-assistant/preview/index.html

> `preview` 是公开开发预览指针，不代表正式临床发布；`main` 继续保持稳定基线，当前 Draft PR 暂不合并。

## v0.10：全项可编辑

- 结构化急症卡、抢救药物卡、临床流程卡：支持编辑标题、摘要、红旗征象、步骤、剂量/参数、液体、复评目标、安全提醒和个人备注。
- 普通主诉、未核验急症/流程：支持补充本机自定义内容。
- 计算工具：每一项可补充本机说明，不改变已锁定的高风险公式/决策边界。
- 急诊病历：每个病历模板正文均可编辑、保存并恢复默认。
- 个人修改保存在浏览器 LocalStorage；临床卡一旦修改即标记“本机已编辑 · 需复核”。
- 指南默认内容、来源和版本与个人修改分离；可单项或全部恢复默认。
- 结构化临床卡支持个人编辑 JSON 导入/导出。

## 当前临床模块

已覆盖：成人心搏骤停、胸痛/ACS、严重过敏反应、脓毒症/感染性休克、低血糖、癫痫持续状态、哮喘、严重创伤/大出血、高血压急症、急性心衰/肺水肿、急性肺栓塞、阿片类中毒、有机磷/氨基甲酸酯中毒、急性缺血性卒中、自发性脑出血、动脉瘤性蛛网膜下腔出血、急性主动脉综合征、DKA/HHS、高钾、热射病、溺水、上消化道出血、食管胃静脉曲张出血、急性胰腺炎、意外低体温、一氧化碳中毒、三环类/钠通道阻滞剂中毒、β受体阻滞剂中毒和钙通道阻滞剂中毒。

v0.10 新增：

- 细菌性脑膜炎：NICE NG240（2024；2025 更新链接），检查与抗菌治疗并行，院内疑似后尽快 IV 抗菌药，目标到院后 1 小时内。
- 脑膜炎球菌病：NICE NG240，强调紧急转运、早期 ceftriaxone/benzylpenicillin（不延误转运）及脓毒症复苏。
- 肾上腺危象：NICE NG243（2024）+ Society for Endocrinology，hydrocortisone 100 mg IV/IM 立即，后续 200 mg/24 h 或 50 mg q6h，并以 0.9% NaCl 复苏。
- 严重症状性低钠：Society for Endocrinology，症状优先于单一血钠数字；高渗盐水使用需严密监测和过度纠正防护。
- 急性低钙：Society for Endocrinology 2016 + 2019 addendum，加入 ECG 监护下 10% calcium gluconate 急救与维持方案。
- 急性高钙：Society for Endocrinology 急诊指导，补液优先，双膦酸盐和二线治疗保持部分核验/本地复核状态。
- 新增药物卡：氢化可的松（肾上腺危象）、高渗氯化钠（症状性低钠）、葡萄糖酸钙（急性低钙）、头孢曲松（脑膜炎）、地塞米松（细菌性脑膜炎）、唑来膦酸（急性高钙）。

## 产品安全原则

- 泛主诉不自动锚定单一疾病；明确诊断或高度特异红旗入口才进入疾病指南卡。
- 默认临床内容显示核验状态、指南名称、版本和核验日期。
- 用户本机修改与指南默认内容分层显示，个人修改必须重新临床复核。
- 卒中溶栓、主动脉综合征、抗凝逆转、动脉瘤封闭、TIPS/BRTO、危重中毒等复杂高风险治疗不压缩成单一按钮。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定或部分核验。
- 儿童、孕产妇、特殊人群、具体药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。

## 技术功能

- 响应式首页与移动端底部导航
- 主诉 / 明确诊断双入口
- 红旗入口与全局搜索
- 抢救用药、急救流程、计算工具、急诊病历、待办
- 收藏与最近使用（LocalStorage）
- 交班快速清单
- PWA manifest、应用图标、基础离线缓存
- 指南来源库和临床核验状态
- 临床内容按 batch 拆分，可独立审查与回退
- 全项本机编辑：临床卡、普通流程/主诉、工具说明、病历模板
