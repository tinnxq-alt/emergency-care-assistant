## v0.14：病房 166 种药品自动关联

急救助手不再复制维护一份病房药库，而是直接读取“基层用药助手”的稳定病房目录：

- 数据来源：`https://tinnxq-alt.github.io/primary-medication-assistant/drugs.js`。
- 同时加载 `catalog-retirements.js`，因此停用的“丹七片”会自动被排除，保持当前 166 种病房药品。
- 用药页新增第三个标签：`病房药库（166）`，按治疗分类浏览并支持药名、通用名、规格、厂家搜索。
- 急救药物卡按通用名/别名自动匹配病房药品，并显示“病房有药 + 规格”。
- 自动关联结果同时可出现在首页和急症页打开的药物临床卡中。
- 匹配优先使用标准化通用名，并对头孢曲松、地塞米松、人胰岛素等带临床场景后缀的急救卡使用保守别名映射，避免宽松模糊匹配造成误关联。
- 在线同步成功后保存一个本机最小缓存；病房药库暂时无法加载时，可使用最近一次成功同步的缓存。
- 病房“有药”只表示可获得性，不代表急救指南首选、适应证或推荐剂量。

### 数据职责分离

- `基层用药助手`：病房药库的名称、通用名、规格、剂型、厂家、药品分类和药品说明书资料。
- `急救诊疗助手`：急症场景、急救流程、权威指南剂量/参数、安全边界。
- `本院抢救车`：抢救车现场库存、数量、有效期和盘点状态。

三个来源可以互相显示“可获得性”，但不会互相覆盖指南来源或个人编辑。

## v0.13：本院抢救车库存与心律失常急救

### 本院抢救车库存管理

根据用户提供的《抢救车示意图》照片保留 18 个药品/液体默认条目，并新增本机盘点能力：规格、数量、库存状态、有效期、最近复核日期和备注可编辑；支持临期/过期提示、JSON 导入导出和恢复照片默认。

### 心律失常急救扩展

依据 2025 AHA Adult Advanced Life Support / 2025 AHA Algorithms，并结合 2023 ACC/AHA/ACCP/HRS AF 指南，已覆盖症状性心动过缓、规则窄 QRS 心动过速、宽 QRS 心动过速（有脉）、房颤/房扑伴快速心室率，以及相关阿托品、胺碘酮、腺苷药物卡。

## 当前主要能力

- 多页面底部导航：首页 / 急症 / 用药 / 待办均为独立页面。
- 指南药物、本院抢救车、病房药库三层联动。
- 急症、药物、临床流程、普通流程、工具说明、病历模板支持本机编辑；个人修改与指南默认内容分层。
- 指南来源、版本、核验状态与个人编辑分开保存。
- PWA 与基础离线缓存。
- 临床内容按 batch 拆分，方便独立审查和回退。
