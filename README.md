第三批：急性缺血性卒中、自发性脑出血、急性主动脉综合征、DKA/HHS、高钾血症、热射病、溺水、上消化道出血。

第四批 v0.7：动脉瘤性蛛网膜下腔出血（aSAH）。

- 最新主来源：2026 ESO/EANS/ESMINT 联合指南

- 核心内容覆盖：CT-first 评估、责任动脉瘤识别、24 小时内处理、再出血预防、尼莫地平、正常容量、脑积水、癫痫、血管痉挛/迟发性脑缺血与转神经血管中心

## SAH 特别安全设计

- 不把普通“头痛”自动诊断为 SAH；只有明确诊断或高度特异“雷击样头痛/疑似 SAH”入口进入指南卡。
- 动脉瘤未封闭前不硬编码一个适用于所有患者的血压目标；强调减少血压波动、避免低血压和脑灌注不足。
- 常规抗纤溶治疗不作为标准路径；2026 欧洲联合指南不推荐常规使用。
- 尼莫地平明确标注仅可肠内使用，严禁静脉/肠外给药。
- 尼莫地平成人标准处方标签：60 mg 每 4 小时，21 天，SAH 后 96 小时内开始；具体国内制剂与特殊人群仍需核对本地说明书。

## 产品安全原则

- 泛主诉不自动锚定单一疾病；只有明确诊断或高度特异的红旗入口进入疾病指南卡。
- 每条临床内容显示核验状态、指南名称、版本和核验日期。
- 卒中溶栓、主动脉综合征、抗凝逆转、动脉瘤封闭等复杂高风险治疗不压缩成单一按钮。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定。
- 儿童、孕产妇、特殊人群、药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。
