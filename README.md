# 急救诊疗助手

基层急诊、抢救与值班工作台。

## 开发原则

- `main` 保持稳定基线；开发在 `agent/emergency-assistant-v0.2`，预览同步到 `preview`。
- 临床内容显示指南核验状态和一手来源。
- 本院抢救车与病房药库只表达可获得性，不改变指南优先级。
- **库存不设置状态。** 抢救车只记录名称、规格、数量、位置、有效期、最近复核日期和备注，不使用“正常 / 待补 / 缺货 / 已停用”等状态字段。
- 历史本机数据里的 `stockState` 字段已停用，重新保存或导入时会自动忽略/清理。
- 高风险剂量、浓度、配液、泵速和相容性只在有可靠来源时固化；本院制剂仍需核对实物标签和院内制度。

## 页面

- `index.html`：首页 / 急救工作台
- `emergency.html`：急症
- `drugs.html`：指南用药、本院抢救车、病房药库
- `todo.html`：值班待办

## 抢救车

当前照片录入 18 个药品/液体条目。支持本机编辑规格、数量、有效期、最近复核日期和备注。抢救车里的药物可与临床卡保守关联，但“有药”不等于“应该用”。

## 病房药库

通过基层用药助手公开目录加载病房药品，并按通用名/保守别名与急救药物关联。药库目录与临床推荐保持独立。

## 临床核验

已累计完成多轮既有内容核验，最近重点包括 GINA 2026、GOLD 2026、NICE NG111、NICE NG217、NICE NG240、Society for Endocrinology 2022、Endocrine Society 2022/2023、AHA 2025、RCUK/ERC 2025、ADA 2026 等。

详细记录见 `CLINICAL_AUDIT*.md` 与 `CRASH_CART_AUDIT_V017.md`。
