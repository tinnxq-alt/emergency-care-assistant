## 当前临床内容

首批已绑定/核验：成人心搏骤停、胸痛/ACS、严重过敏反应、脓毒症/感染性休克、低血糖、癫痫持续状态、哮喘急性发作；COPD 急性加重已绑定 GOLD 2026，细节仍分批解锁。

第二批新增：

- 严重创伤/大出血：欧洲严重创伤大出血与凝血病第六版指南（2023）
- 高血压急症：AHA 2024 急性期血压管理科学声明
- 急性心力衰竭/肺水肿：2022 AHA/ACC/HFSA 心衰指南（当前部分核验）
- 急性肺栓塞：2026 AHA/ACC 多学会成人急性 PE 指南
- 阿片类中毒：AHA 2025 特殊复苏情境
- 有机磷/氨基甲酸酯中毒：AHA 2025 特殊复苏情境（部分参数继续锁定）
- 新增/扩展药物：氨甲环酸、纳洛酮、氯解磷定及毒物场景阿托品

## 产品安全原则

- 泛主诉（呼吸困难、一般休克、意识障碍、一般创伤、中毒暴露等）不自动锚定单一疾病。
- 只有明确诊断或高度特异的红旗入口进入疾病指南卡。
- 每条临床内容显示核验状态、指南名称、版本和核验日期。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定。
- 儿童、孕产妇、特殊人群、药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。

## 技术功能

- 响应式首页与移动端底部导航
- 主诉 / 明确诊断双入口
- 红旗入口与全局搜索
- 抢救用药、急救流程、计算工具、急诊病历、待办
- 收藏与最近使用（LocalStorage）
- 交班快速清单
- PWA manifest、应用图标、基础离线缓存
- 指南来源库和临床核验状态
