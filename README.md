## 当前临床内容

第一批：成人心搏骤停、胸痛/ACS、严重过敏反应、脓毒症/感染性休克、低血糖、癫痫持续状态、哮喘急性发作；COPD 急性加重已绑定 GOLD 2026。

第二批：严重创伤/大出血、高血压急症、急性心力衰竭/肺水肿、急性肺栓塞、阿片类中毒、有机磷/氨基甲酸酯中毒。

第三批 v0.6：

- 急性缺血性卒中：2026 AHA/ASA
- 自发性脑出血：2022 AHA/ASA
- 急性主动脉综合征：2022 ACC/AHA
- DKA/HHS：2024 ADA/EASD/JBDS/AACE/DTS 共识
- 高钾血症：RCUK 2025
- 热射病：RCUK 2025
- 溺水：RCUK 2025
- 上消化道出血：ACG 2021
- 新增高钾/代谢急症药物卡：氯化钙、葡萄糖酸钙、普通胰岛素（高钾/DKA）

## 产品安全原则

- 泛主诉不自动锚定单一疾病；只有明确诊断或高度特异的红旗入口进入疾病指南卡。
- 每条临床内容显示核验状态、指南名称、版本和核验日期。
- 卒中溶栓、主动脉综合征、抗凝逆转等复杂高风险治疗不压缩成单一按钮。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定。
- 儿童、孕产妇、特殊人群、药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。

## 技术功能

- 响应式首页与移动端底部导航
- 主诉 / 明确诊断双入口
- 红旗入口与全局搜索
- 抢救用药、急救流程、计算工具、急诊病历、待办
- 收藏与最近使用（LocalStorage）
- 交班快速清单
- PWA manifest、应用图标、基础离线缓存
- 指南来源库和临床核验状态
- 临床内容按 batch 拆分，可独立审查与回退
