## v0.4 临床内容层

新增 `clinical-data.js`、`clinical.js`、`clinical.css`，把产品原型升级为“来源绑定的临床摘要卡”。每张已核验卡展示：

- 核验状态、核验日期、指南版本
- 临床摘要与红旗征象
- 首要处置步骤与动态复评
- 已核验的关键剂量/参数
- 禁忌、易错点和安全提醒
- 可直接打开的一手官方指南来源

首批已接入：

- 成人心搏骤停与 ROSC 后关键氧合目标（AHA 2025 CPR/ECC）
- 成人有脉心动过缓/心动过速算法（AHA 2025）
- 急性胸痛/ACS 快速评估（2025 ACC/AHA ACS + 2021 Chest Pain）
- 严重过敏反应（RCUK/ERC 2025 + RCUK anaphylaxis guidance）
- 脓毒症/感染性休克（Surviving Sepsis Campaign 2026）
- 低血糖（ADA Standards of Care 2026）
- 惊厥性癫痫持续状态（NICE NG217，2025 更新）
- 哮喘急性发作（GINA 2026，采用原创摘要，不复制受版权保护的指南图表/原文）
- COPD 急性加重已绑定 GOLD 2026，详细治疗数字尚未逐条核完，因此继续锁定

## 安全设计

- 采用保守路由：只有明确诊断或高度特异的红旗入口才自动打开对应疾病指南卡。
- 泛主诉不自动锚定单一诊断：例如“呼吸困难”不会自动当作哮喘，“休克”不会自动当作脓毒症，“意识障碍/一般抽搐”不会自动当作癫痫持续状态，“低血糖样症状”也不能替代床旁血糖确认。
- 未完成逐条核验的高风险剂量、配液浓度、泵速、评分阈值继续锁定。
- 药物条目区分“已核验 / 部分核验 / 待核验”。
- 具体药品规格、相容性、特殊人群与本机构标准仍需结合说明书和本地制度复核。
- 涉及患者数据时需要另行设计权限、隐私、审计和数据安全，目前预览版不上传患者信息。
