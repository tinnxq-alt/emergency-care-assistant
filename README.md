# 急救诊疗助手

基层急诊、抢救与值班工作台。当前开发版保留多页面导航、临床指南核验、病房药库自动关联、本院抢救车、待办、本机编辑与 PWA 离线缓存。

## 当前开发原则

- `main` 保持稳定基线；开发继续在 `agent/emergency-assistant-v0.2`，公开预览同步到 `preview`。
- 临床内容采用 `已核验 / 部分核验 / 已绑定来源 / 未建立指南急救卡` 等临床状态，并显示一手来源。
- 本院抢救车与病房药库只表达“本院可获得性”，不改变指南优先级。
- **库存不设置状态标签。** 抢救车仅保存名称、规格、数量、位置、有效期、最近复核日期和备注；不再使用“正常 / 待补 / 缺货 / 已停用”等库存状态。
- 本机修改与指南默认内容分层保存，避免把个人编辑伪装成指南核验内容。
- 高风险剂量、浓度、配液、泵速和相容性只在能由可靠来源核验时固化；本院制剂仍需核对实物标签和院内制度。

## 页面

- `index.html`：首页 / 急救工作台
- `emergency.html`：急症
- `drugs.html`：指南用药、本院抢救车、病房药库
- `todo.html`：值班待办

## 抢救车

当前照片录入 18 个药品/液体条目。抢救车页面支持本机编辑规格、数量、有效期、最近复核日期和备注。历史版本中的 `stockState` 字段已停用；旧本机数据在重新保存或导入时会被忽略。

抢救车里的药物会与急救临床卡尽可能保守关联，但“有药”不等于“应该用”。对当前未建立现代急救指南卡的药物，只显示临床安全边界和来源情况，不给库存打“待核验”标签。

## 病房药库

通过基层用药助手公开目录自动加载病房药品，并按通用名/保守别名与急救药物关联。库存目录与临床推荐保持独立。

## 当前临床审计

已累计完成多轮既有内容核验，最近一轮重点包括：

- GINA 2026：成人/青少年急性哮喘氧疗目标 92%–95%。
- GOLD 2026：COPD 急性加重路径，甲基黄嘌呤不作为常规推荐。
- NICE NG111：成人急性肾盂肾炎。
- NICE NG217（2025 更新）：惊厥性癫痫持续状态。
- NICE NG240：细菌性脑膜炎流程。
- Society for Endocrinology 2022：严重/中度严重症状性低钠血症。
- Endocrine Society 2022/2023：恶性肿瘤相关高钙血症分支。
- AHA 2025、RCUK/ERC 2025、ADA 2026 等既有急救/用药内容继续保留。

详细审计记录见 `CLINICAL_AUDIT*.md` 与 `CRASH_CART_AUDIT_V017.md`。
