这是一个独立的基层急诊、抢救与值班工作台项目，与“基层用药助手”分开维护、分开部署、分开回退。

## v0.11：底部导航改为独立页面

底部导航不再只是当前首页的滚动/弹窗按钮：

- `首页` → `index.html`：总工作台、搜索、红旗入口、流程、工具、病历与值班概览。
- `急症` → `emergency.html`：独立红旗、按诊断/按主诉、搜索与临床指南卡页面。
- `用药` → `drugs.html`：独立抢救药物目录，按类别分组和搜索，显示核验状态。
- `待办` → `todo.html`：独立值班待办页面；与首页待办共用同一份 LocalStorage 数据。

四个页面共用同一套临床数据、指南来源和本机编辑数据。已在首页做过的个人修改，在急症/用药页面继续生效。

## 全项可编辑

- 结构化急症卡、抢救药物卡、临床流程卡：可编辑标题、摘要、红旗、步骤、剂量/参数、液体、复评目标、安全提醒和个人备注。
- 普通主诉、未核验急症/流程：可保存本机自定义内容。
- 尚未形成完整结构化卡的待核验药物：也可补充本机备注，但仍明确标记需要重新临床复核。
- 计算工具：每项可补充本机说明，不改变高风险公式/决策安全锁。
- 急诊病历：每个模板正文可编辑、保存和恢复默认。
- 个人修改仅存浏览器 LocalStorage；不会覆盖 GitHub 中的指南默认数据和来源版本。
- 结构化临床卡支持编辑 JSON 导入/导出及集中管理。

## v0.11 临床扩展

在既有心搏骤停、ACS、严重过敏、脓毒症、神经急症、创伤、代谢/电解质急症、中毒、消化道出血、内分泌急症等模块基础上，本批新增/更新：

- 成人社区获得性肺炎：NICE NG250（2025；2026 年 1 月更新），加入 CRB65/CURB65、照护层级、影像/抗菌时效和 48 小时 IV→口服复评。
- 急性肾损伤：NICE NG148（更新至 2024），加入肌酐/尿量识别、尿检、梗阻影像、药物审查及肾替代治疗升级条件。
- 急性肾盂肾炎：NICE NG111（安全信息更新至 2024），加入尿培养、口服/IV 分层、48 小时复评和脓毒症/梗阻转诊逻辑。
- COPD 急性加重：主来源更新绑定 GOLD 2026；保留氧疗、激素、抗菌药、NIV 等高风险参数的本地方案/血气/药品说明书复核要求。

新增流程和记录入口：肺炎严重度与转诊流程、AKI 快速评估流程、肺炎记录、AKI 记录、急性肾盂肾炎记录。

## 产品安全原则

- 泛主诉不自动锚定单一疾病；明确诊断或高度特异红旗入口才进入疾病指南卡。
- 默认临床内容显示核验状态、指南名称、版本和核验日期。
- 用户本机修改与指南默认内容分层显示，个人修改必须重新临床复核。
- 卒中溶栓、主动脉综合征、抗凝逆转、动脉瘤封闭、TIPS/BRTO、危重中毒等复杂高风险治疗不压缩成单一按钮。
- 尚未能从一手来源逐条确认的剂量、浓度、泵速和治疗阈值保持锁定或部分核验。
- 儿童、孕产妇、特殊人群、具体药品规格/相容性需要单独核验。
- 本项目不能替代完整指南、本机构制度、药品说明书、临床判断和上级医院转诊路径。

## 技术功能

- 四页面底部导航：主页 / 急症 / 用药 / 待办
- 响应式移动端与桌面布局
- 主诉 / 明确诊断双入口、红旗入口与搜索
- 抢救用药、急救流程、计算工具、急诊病历、待办
- 收藏与最近使用（LocalStorage）
- 交班快速清单
- PWA manifest、应用图标、四页面基础离线缓存
- 指南来源库和临床核验状态
- 临床内容按 batch 拆分，可独立审查与回退
- 全项本机编辑、恢复默认；结构化卡支持 JSON 导入/导出
