# 急救诊疗助手 v0.3（开发预览）

这是一个独立的基层急诊、抢救与值班工作台项目，与“基层用药助手”分开维护、分开部署、分开回退。

## 当前已完成

- 响应式首页与移动端底部导航
- 急救工作台：急症处置、抢救用药、急救流程、计算工具、急诊病历、待办
- 红旗入口：无反应、严重呼吸困难、休克、抽搐/意识障碍、严重过敏、大出血/创伤、胸痛高危、中毒
- “按主诉 / 按诊断”双入口
- 全局搜索：主诉、诊断、药物、流程、工具、病历模板
- 抢救药物结构化详情字段（临床数值默认锁定）
- 流程卡与结构化急诊病历骨架
- LocalStorage 值班待办
- 收藏与最近使用（本机保存）
- 交班快速清单
- PWA manifest、应用图标与基础离线缓存
- 在线/离线状态提示
- 内容核验状态提示

## 安全边界

当前是产品开发预览，不是临床决策系统。药物剂量、给药途径、稀释方式、评分规则、治疗阈值和具体诊疗流程在正式上线前必须：

1. 绑定权威指南或药品说明书来源；
2. 标注版本与更新时间；
3. 由临床人员逐项审核；
4. 高风险字段保留醒目提示与复核机制；
5. 涉及患者数据时另行设计权限、隐私、审计与数据安全。

## 开发策略

- `main`：稳定基线，暂不合并当前功能。
- `agent/emergency-assistant-v0.2`：当前 v0.3 开发预览分支（沿用原分支名以保留 PR 历史）。
- `preview`：公开开发预览指针，可随开发分支更新，不代表正式发布。
- 所有功能继续保留在 Draft PR，确认满意后再决定是否合并。
